NInfer Windows 双 V100 · 0.1.1 预览版

1. 安装适合自己显卡的 NVIDIA 驱动。本机验证：Windows 11 + GRID 553.62 + 两张 V100-SXM2 16GB，WDDM。
2. 完整解压 ZIP 到自己有写权限的目录，双击 NInfer.exe。不要在压缩包内直接运行，不要单独复制 EXE。
3. 点击“选择本地模型”，或“下载推荐模型”。下载需要约23.8GB磁盘空间，支持断点续传，并校验 SHA-256。
4. 选择上下文，点击“启动模型”。推荐128K；显存紧张时选择16K。等日志显示服务就绪。
5. 在输入框提问并点击“发送单轮提问”；每次问答独立，不自动携带历史。也可以复制 API 地址连接自己的聊天客户端，模型名 coder390，API key 留空（客户端强制填写时可填 local）。
6. 用“停止 / 取消”释放显存；正常关闭启动器也会停止它自己启动的服务。

应用已附带 CUDA 运行时和 VC++ 运行库，无需安装 CUDA Toolkit、Python 或 Visual Studio。
使用 Windows 自带 .NET Framework 4.8；仅验证 Windows 11 64位。
程序不修改驱动、TCC/WDDM、全局环境变量或其他服务。推理只监听本机，不对局域网开放。
此包针对 NVIDIA 设备0、1均为V100（至少16GB）。RX550作为显示输出不影响该NVIDIA编号。

模型：Merkyor 发布的 Qwen3.8-27B-Coder390-EfficientThink-W4A4-MTP-DFlash2.ninfer v3。
仅支持本项目登记的模型，不能直接加载普通 GGUF、safetensors 或任意同后缀文件。
MTP严格校验有1/64位置不一致，启动器默认关闭MTP。DFlash/Vision不在此预览版的验收范围。
20万容量完成了分配及短问答，不代表填满上下文后的速度和质量；游戏会减少可用显存。
本包未做代码签名。首次运行可能显示未知发布者；请从本仓库Release下载并核对SHA256SUMS.txt。

日志与上次模型路径：%LOCALAPPDATA%\NInferV100X2
卸载：关闭启动器后删除解压目录；模型和上述设置目录可自行保留或删除。
源代码、上游来源、构建与许可证：https://github.com/Havensky-stack/windows-ninfer-V100X2
